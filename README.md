# meekono-integrations
Integration project connecting CS-Cart, HubSpot, WATI, Zapier and Constant Contact for the Meekono sourcing platform.

## Integration Developer (Contract, Remote)
## Automation & Marketplace Integration
## Contract type: Short-term project

**About The Company**
Meekono is a B2B sourcing platform and ecosystem builder that enables global retailers to seamlessly source handcrafted products from 30 African countries, and empowers vendors with market readiness tools and support to engage effectively and equitably with global markets.

We’re currently building an integrated digital system to streamline our vendor and buyer journeys and operational workflows.

**Role Overview**
The developer will help connect and automate across vendor onboarding, buyer engagement and end-to-end order management our existing systems and workflows, starting with integrations between:
- CS-Cart (turnkey multi-vendor wholesale marketplace platform)
- HubSpot (CRM)
- WATI (vendor and buyer messaging automation)
- Zapier (workflow automation)
- Constant Contact (email campaigns)

**Key Deliverables**
   ## 1. Integration Setup
    - Connect CS-Cart with HubSpot via API or webhooks
    - Implement Zapier workflows between systems
    - Ensure contacts, orders, and vendor records sync correctly

   ## 2. Automation Development
      ## Buyer workflows
         - New customer signup → create HubSpot contact
         - Order placed → create HubSpot deal
         - Lookbook download → add to email list

      ## Vendor workflows
          - Vendor signup → create vendor record
          - Vendor approved → trigger WhatsApp onboarding
          - Product uploaded → notify review team
          - Product approved → notify vendor
  ## 3. WhatsApp Automation
    Configure WATI workflows including:
  - Vendor onboarding process
  - Account approval notifications
  - Product upload
  - Vendor order tracking
  ## 4. Data Sync
    - Ensure consistent data flow between systems including:
    - Customer records
    - Vendor profiles
    - Order data
    - Product approvals
  ## 5. Documentation of the integration architecture
  ## 6. Testing and debugging support

**Required Skills**
  - Experience with CS-Cart API / marketplace and e-commerce platforms
  - Strong experience with REST APIs
  - Experience with Zapier or workflow automation tools
  - Integration experience with CRM platforms (HubSpot preferred)
  - Webhook implementation
  - Basic knowledge of database and data mapping
  - Experience integrating WhatsApp Business API

**Project Scope**
This is a short-term integration project estimated at 10–20 hours.
Future opportunities may be available for additional development work.
